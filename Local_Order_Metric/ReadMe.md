This folder contains various scripts related to calculating the local order metric of glassy ices using reference motifs derived from crystalline phases of ice. 
Of particular interest are ices 1h, IV, and VII
This work is inspired by that of F. Martelli (https://doi.org/10.1103/PhysRevMaterials.2.075601 , https://doi.org/10.1103/PhysRevB.97.064105)
